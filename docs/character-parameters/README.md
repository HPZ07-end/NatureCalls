# 人物参数第一版初稿

更新日期：2026-11-26。状态：Proposed Change，待人类讨论批准具体数值。

本初稿分为三名角色共用的统一参数，以及矮快型（Swift）、均衡型（Balanced）、高伸型（Tall）的差异参数。按本次要求，小孩的定位为移动最快、小便瞄准最稳定；本文暂将小孩对应矮快型，作为供讨论的角色配置，不直接绑定工程中的模型与能力。

项目语义以 [GLOSSARY](../../GLOSSARY.md) 为唯一权威，工程现状见 [DEVELOPMENT_STATUS](../DEVELOPMENT_STATUS.md)。数值为试玩起点，尚未应用到运行时代码，也未经平衡验证。

## 设计边界

- 公共分支已记录 CharacterProfile（角色参数）方向：玩法能力来自运行时参数，模型负责外观；本地 Glossary 仍保留模型只影响外观的规则。本文提出三种配置，不覆盖既有语义差异。
- 本次明确方向是小孩移动更快、瞄准更准；三种配置的具体数值及小孩与 Swift 的对应关系仍作为提案。
- 本版“跑速”指正常 WASD 的常规移动速度，不额外增加冲刺键或体力系统。
- 如厕速度以一次实际排泄的持续时间表达，不增加尿量或粪便质量等模拟单位。
- 小便参数针对公共分支已记录的男性站立小便范围，不自行补充女性小便机制。

## 统一参数

以下参数三者相同。后续实现时，角色配置只覆盖下一节列出的差异参数。

### 移动与姿态

- **跳跃初速度：6.0 米/秒。** 沿用当前工程值。
- **重力加速度大小：20 米/秒²。** 沿用当前代码；理想起跳增高约 0.90 米，实际可达高度以场景碰撞验证为准。
- **大便时小幅挪动速度：0.30 米/秒。** 拟用于盲拉过程；现有 M1 的 0.30 是落点修正速度，不代表实际角色挪动已经实现。
- **持工具移动速度倍率：1.00。** 暂不增加持工具减速。
- **斜向移动速度上限：与正向相同。** 不叠加提速。

姿态、如厕及通行接管的限制优先于速度参数。第一版不因角色类别改变跳跃能力或碰撞体尺寸；高处触及参数仅用于物品拾取。

### 排泄与瞄准

- **小便基础时长：3.0 秒。** 有效时长 = 基础时长 ÷ 角色小便速度倍率。
- **大便时长：5.0 秒。** 三者一致。
- **鼠标瞄准响应倍率：1.00。** 三者一致，不通过改变灵敏度制造准度优势。
- **角色额外大便落点随机偏移：0 米。** 盲拉提案不叠加角色专属随机散布。
- **M1 参考扰动幅度：0.04–0.35 米。** 当前按急迫值线性变化；再乘以角色小便瞄准扰动倍率，才得到拟议的有效幅度。
- **M1 参考目标半径：0.25 米。** 三者使用相同目标与判定。
- **M1 小便合格准度：70%。** 三者使用相同阈值。
- **M1 大便三档边界：80%、40%。** 三者使用相同阈值。

小便实际准度 = 落点在目标区内的累计时间 ÷ 实际排泄累计时间。例如 3 秒中有 2.4 秒落在目标区，实际准度为 80%。角色的“更准”通过减小扰动实现，不设置固定命中率，也不扩大某名角色的目标区。

实际排泄时长不含接近、对位和镜头过渡。持续时间与速度倍率不同时作为独立可编辑参数，小便有效时长由公式推导。

公共分支的新小便方向按真实轨迹、落点与入射角判断，盲拉按用力时臀部投影判断。上述 M1 时间比例判定仅供当前原型参考，不与新判定同时结算。轨迹版本接入后，扰动倍率可保留，基础扰动角度需在统一距离重新标定，不能直接把米数当作角度。

### 状态与携带

- **M1 急迫值上限参考：100。**
- **M1 急迫值基础增长：100/60，约 1.67/秒。** 角色差异只乘增长倍率。
- **M1 如厕期间增长：0。**
- **M1 大便后急迫值：清零；小便后：减半。**
- **恶心值增加倍率：1.00。** 三者相同，触发与失败规则沿用权威定义。
- **携带容量：1 件。** 卷纸与工具共用容量。
- **水平交互距离参考：1.5 米。** 取自现有 NeedsRules；并非工程所有设施都已统一使用此距离。

急迫值正在等待整体重做，因此下一节的增长差异仅供 M1 对比实验，不补完新的行动限制、舒爽增益或失败条件。从 0 涨满的参考时间也不等于开局剩余时间，现有开局值非零。

### 清洁与维修

- **拖把清洁：3.0 秒。**
- **疏通：5.0 秒；修门：5.0 秒。** 对应 [维修与清理初稿](../repair-and-cleaning/README.md)，仍属提案。
- **基础洗手时长：3.0 秒。** 有效时长 = 基础时长 ÷ 角色洗手速度倍率，属于新提案。
- **清洁、维修速度倍率：均为 1.00。** 三者相同。

作业倍率只改变时间，不改变工具要求、步骤顺序、完成效果或中断规则。

## 三者差异参数

以下每个参数至少有一名角色不同。其余参数统一使用上一节的值，不再逐角色重复定义。

### 矮快型 Swift 小孩

- **常规移动速度：4.2 米/秒。** 三者最快，比均衡型快 20%。
- **爬行速度：2.2 米/秒。** 三者最快。
- **小便瞄准扰动倍率：0.60。** 三者最稳定，比均衡型扰动幅度小 40%；不表示命中率直接增加 40%。
- **小便速度倍率：1.20。** 实际排泄 **2.5 秒**。
- **M1 急迫值增长倍率：1.20。** 增长 **2.0/秒**，从 0 涨满约 **50 秒**。
- **高处物品触及高度：距脚下 1.30 米。**
- **洗手速度倍率：0.75。** 提议实际洗手 **4.0 秒**。

定位：快速跑动和精准小便。代价是更难憋住、高处取物受限、洗手较慢。

### 均衡型 Balanced

- **常规移动速度：3.5 米/秒。** 沿用当前工程基准。
- **爬行速度：1.8 米/秒。** 沿用当前工程基准。
- **小便瞄准扰动倍率：1.00。** 作为比较基准。
- **小便速度倍率：1.00。** 实际排泄 **3.0 秒**。
- **M1 急迫值增长倍率：1.00。** 增长约 **1.67/秒**，从 0 涨满 **60 秒**。
- **高处物品触及高度：距脚下 1.80 米。**
- **洗手速度倍率：1.00。** 提议实际洗手 **3.0 秒**。

定位：速度、稳定性和触及范围居中，作为试玩与调参基准。

### 高伸型 Tall

- **常规移动速度：3.2 米/秒。** 比均衡型慢约 9%。
- **爬行速度：1.6 米/秒。**
- **小便瞄准扰动倍率：1.10。** 比均衡型扰动幅度大 10%。
- **小便速度倍率：1.00。** 实际排泄 **3.0 秒**。
- **M1 急迫值增长倍率：0.90。** 增长 **1.5/秒**，从 0 涨满约 **66.7 秒**。
- **高处物品触及高度：距脚下 2.10 米。** 三者最高。
- **洗手速度倍率：1.00。** 提议实际洗手 **3.0 秒**。

定位：方便取得高处物品，在 M1 候选规则下更能憋住；代价是移动与爬行较慢、小便瞄准扰动略大。急迫值重做后需重新验证这一优势。

## 差异使用原则

- 三者优劣通过参数配置表达，不在模型脚本中写死。
- 高处触及高度以物品交互锚点相对脚下的高度计算，不等于人物身高、摄像机高度或碰撞体高度。
- 门、水闸等必要设施不受高处物品限制影响；每种角色都必须能完成基本如厕、清洁和地图通行。
- 小孩的准度优势在相同急迫值、站位、鼠标输入和测试时间下比较。小便持续时间不同的完整流程测试另外进行，避免把时间差当作准度优势。
- 同一角色的急迫值差异可能进一步改变 M1 扰动，调参时先固定急迫值，再测试完整一局。
- 正式确认前，工程继续使用既有参数；本文中的三者配置不等于已完成的角色选择或网络同步功能。

## 调参和试玩顺序

1. 以均衡型基准验证探索、转身、风道、跳跃及必要交互。
2. 单独比较 4.2、3.5、3.2 米/秒的移动速度，确认小孩最快，同时不会频繁错过交互点。
3. 使用相同输入与条件比较扰动倍率 0.60、1.00、1.10，确认小孩更容易保持目标。
4. 另外比较小便 2.5 秒和 3.0 秒，确认缩短后仍有足够修正机会。
5. 验证三种触及高度、洗手时长及合作体验，最后再实验急迫值差异。

试玩记录包含角色配置、地图、成功和失误次数、平均实际准度及玩家感受。以上均为待执行验证，本文不宣称通过。
