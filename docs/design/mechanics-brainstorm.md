# 机制讨论：一局怎么推进、急迫值怎么重做

> 讨论记录，**不是权威语义**。结论经人类批准后写进 [GLOSSARY](../../GLOSSARY.md)。暂时不考虑美术。

## 起因（团队 2026-11-25）

- 定时结束（「定时自爆」）不能长期驱动乐趣；「十分钟内拉三次」这种固定次数也不行。
- 能操作的东西太少，只有马桶和卷纸；会加维修。
- 急迫值要整体推翻：越急行动越受限，拉完要有明显的舒爽感。
- 一局怎么推进和急迫值是绑在一起的，要一起设计。

## 候选方案：一局怎么推进

**A. 班次（推荐作为起点）**
- 一局就是一个班次，有时长。急迫值一波一波地来，就是「订单」。
- 能用的马桶比需要的人少：有的堵了、有的倒灌、有的脏了。玩家要选先修、先清还是先拉。
- 结束时按干净值、事故数和舒爽次数给星。干净值归零全队失败（GLOSSARY 已有 Tidiness）。
- 两个班次之间可以升级：多一个隔间、更好的疏通器、更多纸。

**B. 无尽坚守**
- 干净值是团队血量，设施故障越来越频繁，比谁撑得久。规则最简单，但缺少阶段性的目标。

**C. 任务清单**
- 场上随时出现任务（修 A 支路、清 2 号隔间、补纸），完成后拿金币换工具和纸。可以叠加在 A 上，作为「订单」之外的第二条线。

## 急迫值重做的方向

- **分段受限**（数值待定）：轻度不能跳；中度不能跑；重度视野发紧、瞄准抖动、走路踉跄；极限时要按住一个键「憋住」。
- **到顶不直接判负**：当场失禁，留下污物，自己恶心值大涨，团队干净值下降一截。失败与否交给干净值。
- **舒爽感**：拉完后有一段短时间加成（速度、清晰的画面、音效），让「终于拉了」本身成为奖励。
- **可操纵的来源**：喝咖啡跑得更快但急迫值涨得更快。小孩憋不久，大人憋得久（来自 CharacterProfile）。
- **和其他系统的连接**：越急，盲拉和小便越不准，于是更容易弄脏，又要清洁。这就形成「急 → 脏 → 忙 → 更急」的循环。

## 待讨论的问题

1. 一局多长？有几个班次？要不要局间升级？
2. 有没有 NPC 来上厕所，还是只有玩家自己的需求？
3. 失禁要不要设上限（例如每人最多失禁几次，超过就全队失败）？
4. 恶心值保留为单一数值，还是改成多维表现（手脏、衣服脏、闻到味）？
5. 小孩、大人的差异要大到什么程度，才能让分工明显但不破坏平衡？
