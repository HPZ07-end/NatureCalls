# 对抗模式设计稿（Proposed Change，第 2 版）

> 状态：**讨论中，待批准**。批准后写入 [GLOSSARY](../../GLOSSARY.md)，在此之前不是权威语义。
>
> 来源：
> - 用户 2026-11-26：改为非对称对抗；捣蛋者身份公开；专属能力是便秘；人数暂不考虑，平衡靠数值和随机事件；捣蛋者与体型无关。
> - 用户 2026-11-26 第二轮：急迫值到顶后的极限忍耐与失控、恶心值改为倒扣血条、呕吐倒计时、隐式舒爽度、个人便意函数与 2–3 波集体高峰；不用「班次」的说法；不做账号和升级系统。
>
> 目标是完整、可玩、相对成熟的对抗游戏。文中所有数值都是第一版暂定值。

## 1. 一句话

一名**捣蛋者（Saboteur）**想把厕所搞脏、让别人拉不成；其余玩家是**保洁队（Keepers）**，要守住厕所的干净。双方都会急，都得解决自己的生理需求。

## 2. 一局的节奏：便意高峰

- **不按固定时长切段。** 每局有 2–3 波**集体高峰**，由易到难：
  - 第一波小，用来熟悉；
  - 第二波大；
  - 第三波最猛，是决胜的一波，并且只在较长的地图出现。
- **每名玩家的便意按一条个人函数推进**：

  ```
  rate_i(t) = base_i × profile_i × (1 + Σ_k A_k · g(t − T_k − δ_i))
  ```

  - `T_k` 是第 k 波的中心时刻，例如一局的 25%、55%、85%；
  - `A_k` 逐波增大；
  - `g` 是宽度约 40 秒的钟形曲线；
  - `δ_i` 是每人的错峰量，每局随机 ±20 秒。

  这样每波高峰里大家先后告急，不会完全同时，但仍然挤在一个时间窗里，抢坑和排队自然就出现了。
- **局长**：第三波过后再留 30–60 秒收尾，然后结算。地图可以配置波数和局长；默认 3 波，约 8 分钟。
- **小便与大便分开**（待讨论，见第 9 节）：
  - **尿意**：涨得快，每次耗时短，在两波之间零星出现，让玩家不能一直守在一个地方；
  - **便意**：服从上面的高峰函数。

## 3. 急迫值到顶：极限忍耐 → 失控

**极限忍耐**
- 便意到 100 后不立即失控，而是进入一段**不显示时长**的极限忍耐，时长 15–25 秒随机。体型（CharacterProfile）影响它，舒爽度也能延长它。
- 期间的干扰：瞄准抖动、画面晃动或收窄、移动方向偶尔被扭偏。
- 期间的增益：**移动和清洁变快**（肾上腺素），移动 +25%，清洁 +40%。到顶时既危险又能爆发一下。
- 时长不显示，但要有身体信号：心跳声越来越密，屏幕边缘泛红，角色夹腿走。玩家能感到「快不行了」，但不知道还剩几秒。

**失控**（忍耐结束），二选一：
1. **冲向最近的可用马桶**：由程序接管移动，自动寻路。可用的马桶是指没人占用、没有损坏、没有倒灌的。到达后自动坐下，按正常如厕结算。
2. **就地拉**：留下大块污物，局部脏度上升。

选哪一种按概率决定：自身控制力（CharacterProfile，小孩低）越低，离最近可用马桶越远，就越可能就地拉。路上超过 8 秒还没到，也会就地拉。

所以捣蛋者把马桶弄坏、占坑、锁门，会直接让别人失控时找不到马桶。他的破坏和高峰就有了配合。

## 4. 捣蛋者

**便秘（专属被动）**
- 便意按同一条函数，但倍率是 0.5，一局只会急 1–2 次。
- 擦拭用纸减半，最少 1 单位。
- 拉出的东西又干又硬：如果拉在地上，污物权重低，拖把一下就清掉（1 秒）。

**不鼓励捣蛋者随地拉**
- 便秘本身就限制了次数：一局最多急 1–2 次，没有可以反复刷的资源。
- 他的污物权重只有普通的 0.3，又容易清，对胜负影响很小。
- 随地拉对他自己有代价：恶心值大扣，没有舒爽度，下一次便意提前。他在马桶里拉则有舒爽度，还能推迟下次便意。
- 所以对他最划算的是「好好上厕所，把精力花在破坏上」。

**破坏手段**（用现有设施，捣蛋者专用的 E 操作，各有冷却）
- **塞纸**：整卷纸塞进马桶，大幅增加该管路的堵塞值。
- **恶意冲水**：对堵住的马桶冲水，引发倒灌。
- **弄坏**：对冲水把手、龙头或水阀按住 E，把它弄坏，要用工具修。
- **偷藏**：拿走拖把或卷纸藏起来。
- **洒水**：在洗手台接水泼到地上。
- **敲门**（新增）：敲正在使用的隔间门，打断里面玩家的舒爽度累积。

## 5. 恶心值改为「镇定值」（倒扣血条）

- 建议改名为**镇定值（Composure）**：满值 100，被恶心就往下掉，像血条。
- **扣除来源**（第一版数值）：

| 来源 | 扣除 |
| --- | --- |
| 视野里看到地上的屎尿：每处污物，按距离和大小折算 | 约 −1/秒，总共不超过 −4/秒；同一处看久了减半（习惯） |
| 站在积水或污物上 | −2/秒 |
| 被自己的尿或粪溅回 | −15（中） |
| 被别人的屎或呕吐物喷到、被倒灌喷到 | −35（大） |
| 在脏马桶上拉 | −10 |

- **恢复**：视野里没有污物时 +1/秒；舒爽状态下 +3/秒。

**呕吐倒计时**
- 镇定值扣光后进入呕吐倒计时，基础 8 秒。**所在位置的局部脏度越高，倒计时走得越快**，最多 3 倍速。所以玩家可以冲到干净的地方去拖延。
- 倒计时期间：
  - 便意不累积；
  - 不能使用清洁道具或维修工具，不能拾取物品；
  - 只能开关门和冲水。
- 倒计时结束时呕吐：原地留下呕吐物污物，并喷到附近 1.5 米内的其他人（各扣 35），**可能引发连锁呕吐**。之后镇定值回到 50。
- 呕吐和失禁都不直接判负，只制造脏污。

## 6. 隐式舒爽度

- 只在如厕时累积，不显示数值，只有表现反馈：叹气声、画面变暖、角色放松的动作。
- **加舒爽度的行为**：
  - **大便时低头看着它出来**：低头同时帮助对准，不容易拉到外面；
  - 安静不乱动；
  - 用纸好好擦；
  - 冲水；
  - 洗手。
- **减舒爽度的行为**：被敲门、被打断、在脏马桶上拉。
- **作用**：推迟下一次便意（`base_i` 暂时降低，最多约 −30%），并延长下一次极限忍耐。
- 成功如厕后的显式「舒爽」短增益保留：15 秒移动加快、不会滑倒、镇定值恢复加快。

## 7. 脏度场与胜负

- **局部脏度**：一个标量场。在位置 x，脏度 = Σ 每处脏源的权重 × 随距离衰减。
  - 脏源包括：污物、呕吐物、倒灌未清的装置、损坏的设施。
  - 权重为：失禁大块 > 呕吐 > 一般污物 > 积水；捣蛋者的污物 ×0.3。
- **干净值（Tidiness）** = 100 − 全场脏度总量的归一化值，实时变化，清掉就回升。
- **捣蛋者胜**：干净值归零。
- **保洁队胜**：撑过最后一波高峰，到结算时干净值大于 0。
- 局部脏度同时用于：呕吐倒计时的速度、视野扣镇定值、HUD 上的脏区提示。

## 8. 其余沿用第 1 版

- 身份揭晓和结算画面；不做账号和升级。
- 保洁队：清洁、维修、补给。
- 随机事件：水压突增、停电、补给到货、集体闹肚子（插入一个小高峰）、管道工路过。
- 界面（HUD）：干净值条、身份标记、技能冷却。便意只显示到 100 的分段；极限忍耐和舒爽度不显示，只靠表现。

## 9. 还要讨论

1. **大小便是否分成尿意和便意两条？** 我建议分开。小便快、频繁，让玩家在高峰之间也要走动；大便服从高峰。捣蛋者的便秘只作用于便意。
2. **失控冲向马桶的接管程度**：完全自动寻路，还是只强制方向、仍允许小幅操作？我建议后者，更有喜感，也不会让玩家觉得被夺走控制。
3. **镇定值的改名**：镇定值（Composure），或者「胃」「反胃槽」。
4. **轮次规划**：要不要让保洁队互相看见彼此的便意分段，方便安排谁先去、谁顶班？我建议看得见分段，看不见极限忍耐。
5. **视野扣镇定值的习惯衰减**是否需要，避免长时间守在污物旁一直掉血。
