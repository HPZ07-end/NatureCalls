# 维修与清理第一版设计初稿

日期：2026-11-25。状态：Proposed Change，待人类讨论批准。

本初稿整理维修与清理的工具、作用对象、操作流程及完成清单，供团队讨论和后续拆分实现任务。新增用途、数值和状态均为提案；保存本文不代表批准玩法或授权实现。

项目语义以 [GLOSSARY](../../GLOSSARY.md) 为唯一权威，实际完成情况见 [DEVELOPMENT_STATUS](../DEVELOPMENT_STATUS.md)。本文不作为第二份规则权威。

## 阅读依据与适用范围

- 现有基础：拖把清理黑色小球、积水、脏马桶，以及 Map2 A 支路的五步维修原型。
- 公共分支已记录的扩展方向：工具箱内的维修工具实际参与操作、水桶在洗手台接水、管路堵塞与倒灌、维修后恢复排水，以及 E 操作对象、F 使用手持物品的按键方案。
- 本文补充的提案：水桶容量、倒灌马桶的两步清洁、疏通与修门时长、扳手用途、工具数量及中断处理等。
- 本地 Glossary 与公共分支尚有差异，尤其是清洁使用 E 还是 F，以及水桶、倒灌等扩展。本初稿保留差异说明，采用 E/F 方案描述拟议体验；不据此覆盖本地定义或宣称工程已经支持。
- 第一版围绕现有地图与设施推进，不扩展完整事故系统、资源生成机制或 Stage 2/3 架构改造。

## 工具与对象分类

### 环境清理工具

**拖把（Mop）**

- 对象：地面排泄物（当前黑色小球占位）、积水、脏马桶、倒灌后的马桶。
- 用途：清除污物，恢复设施表面的清洁。
- 第一版：普通污物持续清洁 3 秒；倒灌马桶先用水桶冲洗，再用拖把清理。

**水桶（Bucket）**

- 对象：倒灌后的马桶。
- 用途：在洗手台接水，对严重污染进行冲洗。
- 第一版提案：满桶为 3 份水，每次冲洗消耗 1 份；空桶不能冲洗。
- 普通地面污物和普通脏马桶仍可直接用拖把清理。
- 暂不增加拖把耐久、拖把脏污程度或洗拖把机制。

**清洁剂**

- 第一版保留为陈列道具，不设置必须使用清洁剂的污物。
- 先完成拖把与水桶配合，再讨论清洁剂效果。

### 维修工具

**手摇疏通器（Drain Auger）**

- 对象：堵塞的水管（Pipe）。
- 使用位置：对应管路的检修口。
- 第一版提案：玩家必须手持疏通器，关阀后持续操作 5 秒完成清堵。
- 疏通器处理管内堵塞，不清除地面或马桶表面的污物。

**扳手（Wrench）**

- 对象：损坏的隔间门（Door）。
- 用途提案：修复铰链或锁扣，以统一的维修操作表现。
- 第一版提案：持续维修 5 秒，不消耗零件、螺丝或维修材料。
- 第一版不增加水闸损坏或管道漏水的独立维修机制。

### 操作与配套设施

- **水闸（WaterValve）**：隔离维修管路，疏通后恢复供水。
- **检修口**：疏通器的使用位置。
- **上游观察窗**：检查是否堵塞。
- **回流观察窗**：复查排水是否恢复。
- **洗手台（Sink）**：给水桶接水；洗手功能与个人卫生部分衔接。
- **工具箱（Toolbox）**：取出、归还清洁与维修工具。
- **工具架**：用于工具陈列和位置提示。
- **维修围挡**：用于标记维修区域，第一版不增加独立玩法效果。

马桶、小便池、洗手台属于管路关联的用水设施。本初稿明确倒灌马桶的清洁流程；小便池与洗手台倒灌后的独立清洁效果不在本次提案中补完。

## 环境清理流程

### 普通污物

1. 从工具箱取出拖把，或拾取地上的拖把。
2. 对准地面排泄物、积水或脏马桶。
3. 持续清洁 3 秒。
4. 清除该处污物，清洁者沿用现有恶心值增加规则。

中途松开按键、走远或更换目标会中断，本次清洁进度清零。

### 倒灌后的马桶

1. 携带水桶到洗手台接水。
2. 对准污染马桶倒 1 份水，完成冲洗。
3. 归还或放弃当前工具，换成拖把。
4. 对准该马桶持续清洁 3 秒。
5. 马桶恢复清洁状态。

冲洗状态保留到完成清洁或本局结束，允许一名玩家冲洗、另一名玩家拖洗。沿用手上只能拿一件物品的限制，不要求同时携带水桶和拖把。

清洁只处理表面污染，不自动疏通管路。管路仍堵塞时，之后再次倒灌会使马桶重新变脏，并需要重新冲洗与拖洗。

## 管路维修流程

每条参与维修的管路关联自己的水闸、检修口、观察窗和用水设施。

1. **检查**：在上游观察窗确认堵塞，提示对应水闸和检修口。
2. **关阀**：关闭该支路水闸。
3. **疏通**：持疏通器对准检修口，持续操作 5 秒。
4. **开阀**：清堵完成后重新打开水闸。
5. **复查**：在回流观察窗确认排水恢复，完成维修。

第一版补充提案：

- 未关阀时不能开始疏通，提示“请先关闭水闸”。
- 疏通过程中离开、松开按键或更换目标，本次疏通进度清零。
- 已完成的步骤由全队共享，其他玩家可以接着操作。
- 未疏通就重新开阀，固定触发一次阀门倒灌，并在阀门附近留下地面污物。
- 修好后清空堵塞累积值，恢复正常排水；之后仍可能因使用而再次堵塞。
- 维修不自动清除此前留下的污物，需要另行清洁。

Map2 沿用 A 支路原型；Map1 地下维修区的接入另行拆分任务，不视为已经完成。

## 隔间门维修流程

第一版使用地图预设损坏，不加入随机损坏或玩家撞坏门。

- **故障表现**：保持损坏时的打开或关闭状态，无法正常开关、上锁。
- **工具**：扳手。
- **操作**：对准铰链或锁扣区域，持续维修 5 秒。
- **完成结果**：恢复正常开关、上锁和解锁。
- **中断处理**：松开按键、离开或更换目标，本次维修进度清零。

彻底拆门留到后续版本，第一版先完成“损坏 → 找工具 → 修好”的流程。

## 工具与交互规则

### 按键

- **E**：取放工具、拾取物品、操作水闸、观察管路、在洗手台接水。
- **长按 F**：拖把清洁、疏通器疏通、扳手修门。
- **按 F**：水桶对准污染马桶倒水。
- **R**：丢掷手中物品；提案为水桶被丢掷后水量清空，不额外生成积水。

操作前显示目标名称和将执行的动作；持续操作显示进度；不满足条件时显示具体原因，如“需要疏通器”“请先关闭水闸”“水桶已空”“请先用水桶冲洗”。

### 数量与共享

- 第一版提案为每张接入此玩法的地图配置拖把、水桶、疏通器、扳手各 1 件。
- 每名玩家手上只能拿 1 件物品，卷纸与工具共用容量。
- 工具共享使用、不消耗、不刷新；被取走后其他玩家需要寻找、等待或接力。
- 工具可归还工具箱；归还水桶时保留剩余水量。
- 污物状态、水桶水量、冲洗状态、门的维修结果及管路已完成步骤由全队共享。
- 联机操作经服务器校验并同步结果，沿用现有网络判定边界。
